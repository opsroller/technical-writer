# Sources

Reference, for maintainers and reviewers: the material this role was researched from. Paraphrased in this
plugin, never copied.

| Source | Used for |
|---|---|
| [Diataxis](https://diataxis.fr), Daniele Procida: start here, tutorials, how-to guides, reference, explanation, compass, workflow, map, foundations, quality, complex hierarchies, tutorials vs how-to, reference vs explanation | The four kinds, their rules and language, the compass, iterative workflow, structure of docs sets |
| [US BLS Occupational Outlook Handbook: Technical Writers](https://www.bls.gov/ooh/media-and-communication/technical-writers.htm) | Duties and core qualities of the job |
| [Write the Docs: Docs as Code](https://www.writethedocs.org/guide/docs-as-code/) | Docs in version control, review, CI, docs before merge |
| [Google developer documentation style guide](https://developers.google.com/style/highlights) | Voice, conditions first, lists, headings, links, accessibility, global readers |
| [Microsoft Writing Style Guide](https://learn.microsoft.com/style-guide/welcome/) | Second house-style reference for voice and word choice |
| [ISO/IEC/IEEE 26514](https://standards.ieee.org/ieee/26514/4990/) | Standard for designing and developing information for users (cited, not reproduced) |
| [GitLab job family: Technical Writer](https://handbook.gitlab.com/job-families/product/technical-writer) | Responsibilities by level, intermediate to principal |
| [How to grow as a technical writer](https://passo.uno/how-to-grow-senior-tech-writer/), Fabrizio Ferri-Benedetti | What separates senior from junior: independence, impact over output |
| [Google technical writing courses](https://developers.google.com/tech-writing) | Sentence-level clarity, accessibility, error messages |
| [Docs Like Code](https://www.goodreads.com/book/show/34447166-docs-like-code), Anne Gentle | Docs in the development workflow, automation, collaboration with engineers |
| [The Good Docs Project](https://gitlab.com/tgdp) | Open templates for common doc types, used as examples of each kind |
