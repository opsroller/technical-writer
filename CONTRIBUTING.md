# How to contribute to this plugin

1. Branch from `main` and make the change.
2. Put each doc change in the right `docs/<kind>/` folder (see
   [About Diataxis](docs/explanation/about-diataxis.md)); update the
   [reference](docs/reference/index.md) if a skill, workflow or agent changed.
3. Commit with Conventional Commits (`feat:`, `fix:`, `docs:` …).
4. Open a pull request; it is squash-merged with a Conventional Commit title.

New files are GPL-2.0-or-later; add `SPDX-License-Identifier: GPL-2.0-or-later` to code files.
